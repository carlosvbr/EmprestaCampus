# EmprestaCampus
 
Sistema web para gerenciamento de empréstimos de equipamentos acadêmicos. 
 
## Escopo
 
Desenvolver um sistema gerenciamento seguro do ciclo de empréstimo de equipamentos acadêmicos, contemplando solicitação, aprovação, reserva, retirada, devolução, histórico, controle de acesso, notificações e auditoria das operações.
 
## Stack Tecnológico
 
### Frontend
 
- React
- TypeScript
 
### Backend
 
- Python
- Django
- Django REST Framework
 
### Banco de Dados
 
- PostgreSQL
 
### Ferramentas
 
- Git
- GitHub
- GitHub Projects
- Docker
 
## Arquitetura
 
O projeto utilizará uma arquitetura monolítica modular com frontend desacoplado e API REST.
 
O frontend será desenvolvido utilizando React e TypeScript
 
O backend será desenvolvido utilizando Python, Django e Django REST Framework
 
O PostgreSQL será utilizado para armazenamento e persistência dos dados.
